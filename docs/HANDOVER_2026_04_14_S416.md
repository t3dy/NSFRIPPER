### 3. Synth Architecture Review

Reviewed all synth docs (SYNTHMERGE.md, SOLVINGTHECHIPTUNEVSMIDIPROBLEM.md,
synth_fidelity.md, MIDDLE_LAYER_RECOMMENDATION.md, NES_AUDIO_GAPS_AND_NEXT_STEPS.md,
MULTI_CHIP_SCHEMA.md). Key finding: **CC11/CC12 pipeline is correct for 88%
of games**. The existing three-priority cascade (SysEx > CC > ADSR) handles
all standard APU games. The biggest fidelity gaps are:

1. **Expansion audio** (35 games, mostly FDS) — channels silently dropped
2. **Non-linear APU mixing** — formulas documented but not implemented in JSFX
3. **DPCM/DAC** — two mechanisms conflated, percussion missing
4. **Phase reset / retriggers** — solved by SysEx mode but not by CC mode

Decision recorded: current pipeline is right for batch production. SysEx mode
already handles maximum fidelity. Expansion audio is highest-value next investment.

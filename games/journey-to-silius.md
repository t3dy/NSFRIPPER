# Journey to Silius

**24 tracks** extracted via NSF emulation with per-frame APU register capture.

**Driver family:** Family 1: Sparse Envelope (sub-group 1B) — CC11/note: 1.74, CC12/note: 0.01

**DMC:** sample playback and/or DAC writes detected

Each track includes 5-channel MIDI (4 APU + 1 DMC: Pulse 1, Pulse 2, Triangle, Noise, DMC (samples/DAC)) with CC11 volume envelopes and CC12 duty cycle automation, plus a REAPER project with the ReapNES NES APU synthesizer plugin loaded.
